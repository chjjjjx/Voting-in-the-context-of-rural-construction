# 部署指南

## 前置条件

- 一个腾讯云 CloudBase 环境，开通 **PostgreSQL 数据库**、**对象存储**、**静态网站托管**
- 控制台开启 **匿名登录**（村民端依赖它）和 **用户名 + 密码登录**（编辑者依赖它）
- 一个 HTTPS 域名：浏览器只允许在安全上下文里使用麦克风，静态托管默认域名通常已满足
- 能访问 CloudBase JS SDK 的 CDN（`static.cloudbase.net`）；后台页面还内置了 `imgcache.qq.com` 备用源

## 步骤

### 1. 初始化数据库

按 [`database/README.md`](../database/README.md) 依次执行 `00` → `01` → `02` → `03` → `04`。

其中 `03_storage.sql` 是配置说明：优先在控制台创建 `demo-images`、`demo-voice` 两个桶并按下表设置权限。

| 桶 | 公开读 | 上传 | 删除 | 备注 |
| --- | --- | --- | --- | --- |
| `demo-images` | 是 | 仅编辑者 | 仅编辑者 | 地图与作品图片 |
| `demo-voice` | 否 | 匿名 / 登录用户 | 仅编辑者 | 后台用签名 URL 播放 |

两个桶都建议限制单文件 <= 10MB 并限定 MIME 类型。

### 2. 登记编辑者与走访问令

- 在控制台创建编辑者账号，拿到 UID 后写入 `public.editors`（不要写进代码或仓库）。
- 走访问令通过 SQL 单独设置，不写入仓库：
  ```sql
  update public.villages
     set visit_passcode = 'REPLACE_WITH_YOUR_PASSCODE'
   where id = 'demo-village';
  ```

### 3. 准备前端配置

```bash
cp config.example.js config.js
# 编辑 config.js，填入 envId / publishableKey，必要时修改 region / villageId / buckets
```

请只填**你自己新建**的 CloudBase 环境；填别人的环境 ID / 密钥会直接连到对方的数据库与存储桶。

**重要**：`config.js` 被 `.gitignore` 忽略，不会进仓库，但它必须出现在静态托管的目录里。两种做法：

- 手动部署：本地填好后在上传时一并上传 `config.js`；
- 自动部署：在 CI 中从密钥变量生成 `config.js`，不要把它提交到 Git。

若使用 GitHub Pages 等「直接发布仓库文件」的服务，请注意：仓库里没有 `config.js`，页面会提示未配置；此时应改用 CloudBase 静态托管或在构建步骤里生成该文件。**不要为了图方便把真实配置提交进仓库。**

### 4. 上传静态文件

把以下三个文件上传到静态网站根目录，保持同级：

```
index.html
admin.html
config.js
```

入口：`https://你的域名/index.html`，后台：`https://你的域名/admin.html`。编辑者登录后，投票页的「投票记录」按钮会新窗口打开 `./admin.html`，因此两个页面必须放在同一目录。

### 5. 现场初始化

1. 打开后台，用编辑者账号登录，确认能进入统计页。
2. 回到投票页，以编辑者身份点击「上传地图」选择村庄地图图片。
3. 在地图上「添加点位」，进入点位面板为每个方案上传图片、修改名称。
4. 用另一台手机或无痕窗口打开村民页，验证匿名登录、投票、录音提交。
5. 在后台点「刷新数据」，确认票数与语音可播放，再试一次「导出 CSV」。

## 验收清单

- [ ] 村民页能加载地图与点位，刷新后数据仍在（云端而非本地缓存）
- [ ] 同一点位重复投票被拒绝；走访模式可以连续投票
- [ ] 录音能通过 HTTPS 提交，后台可以播放
- [ ] 非编辑者账号登录后台被拒绝
- [ ] 「清空重新投票」后票数与意见归零，点位与图片仍在
- [ ] 浏览器控制台无密钥、口令等敏感输出

## 常见问题

| 现象 | 排查方向 |
| --- | --- |
| 「尚未配置云端参数」 | 静态托管目录缺少 `config.js`，或仍是 `YOUR_` 占位值 |
| 「云端暂时连接不上」 | 匿名登录未开启、SDK CDN 被拦截、环境 ID/地域填错 |
| 「权限不足」/读取失败 | `01_policies.sql` 未执行，或编辑者 UID 未登记到 `editors` |
| 图片上传成功但不显示 | 图片桶未设公开读，或 `getPublicUrl` 返回的域名未放行 |
| 语音无法播放 | 语音桶权限、`createSignedUrl` 权限或 `voice_url` 存储路径格式 |
| 「清空功能尚未启用」 | 未执行 `02_functions.sql` 创建 `reset_huamu_voting_data()` |
| 手机不能录音 | 必须用 HTTPS；确认麦克风权限允许；部分浏览器需改用「选择音频文件」的兼容版本 |
| 改了配置但页面没变化 | 静态托管/CDN 缓存，刷新缓存或在文件名后加查询参数 |

## 数据清空

后台「清空重新投票」只删 `votes` 与 `feedback` 两张表，并尝试删除语音桶中的对应文件；地图、点位、作品与图片保留。投票页编辑者工具里的「清空」按钮则是**删除地图与全部点位**（级联删除作品、投票、意见），两者不同，现场操作前务必看清提示。
